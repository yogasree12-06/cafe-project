# ☕ Ember & Oak — Cafe Website

A modern, responsive, and elegant website for **Ember & Oak**, an artisanal cafe and coffee roastery.

🔗 **Live Demo**: [https://yogasree12-06.github.io/cafe-project/](https://yogasree12-06.github.io/cafe-project/)

---

## ✨ Features

- **Artisanal Aesthetics**: Tailored dark luxury theme with warm amber/gold accents, subtle background grain, and smooth typography.
- **Responsive Layout**: Designed to look stunning on mobile phones, tablets, laptops, and wide desktop screens.
- **Interactive Navigation**: Smooth scrolling between sections including Daily Roasts, Menu, Origin Story, and Visit info.
- **Curated Menu**: Categorized coffee and drink selections (Espresso, Filter, Cold Brew, Not-Coffee, Small Bites).
- **Origin Story & Stats**: Highlights ethical sourcing from partner farms and fresh roasting timelines.
- **Hours & Location**: Clearly formatted cafe schedule and Bengaluru address details with directions.

---

## 🛠️ Built With

- **HTML5**: Semantic markup for accessibility and search engine optimization.
- **CSS3**: Custom design variables, radial gradients, glassmorphism panel styling, and CSS Grid/Flexbox layouts.
- **Google Fonts**: Inter & serif typography for a refined editorial feel.
- **Inline SVG**: Handcrafted coffee cup illustrations and icons with subtle animations.

---

## 🚀 Getting Started

To view this project locally:

1. Clone the repository:
   ```bash
   git clone https://github.com/yogasree12-06/cafe-project.git
   ```
2. Open `index.html` directly in any modern web browser or run with VS Code Live Server.
